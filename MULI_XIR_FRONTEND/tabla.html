Herramientas Tecnológicas

Resumen de tecnologías utilizadas en el desarrollo de la aplicación web

Categoría Herramienta Descripción / Por qué la utilizamos
Lenguajes
Lenguaje HTML ("Lenguaje de etiquetas") Nos permitió estructurar los elementos de la aplicación web, como textos, componentes, contenedores, etc.
Lenguaje JavaScript Nos permite programar la lógica de toda la aplicación como verificaciones, consultas, promesas y componentes reactivos.
Lenguaje CSS ("Hoja de estilos") Nos permite agregar diseño a la aplicación de forma eficiente y reutilizable.
Lenguaje NoSQL ("Lenguaje de consultas") Nos permitió hacer consultas básicas a la base de datos gracias a una extensión de JavaScript llamada Mongoose.
Frameworks
Framework Frontend React + Vite Este framework nos ayudó a programar de manera más eficiente el frontend de la aplicación ya que gracias a su estructura JSX ("JavaScript XML") que en pocas palabras es una extensión de JavaScript que combina su lógica con HTML para crear componentes y páginas más eficientemente.
Framework Backend Node.js Con este framework logramos programar todo el backend de la aplicación utilizando JavaScript ya que este framework usa la lógica JavaScript para programar consultas en el backend lo cual nos facilita el programarlas ya que no tenemos que aprender un lenguaje extra para hacerlo si no que solamente tenemos que aprender sobre el framework en un lenguaje de previo conocimiento.
Framework CSS Tailwind CSS Este framework fue muy útil a la hora de diseñar ya que este framework permite crear diseño de manera más eficiente utilizando clases ya predeterminadas que se añaden directamente al documento JSX, facilitando la creación de aplicación web reactiva.
Herramientas de Desarrollo
Editor de código Visual Studio Code + Extensiones Para codificar toda la aplicación.
Control de versiones GitHub La más popular para administrar las versiones de la aplicación y la más fácil para mandar el proyecto directamente a producción. Permite guardar un proyecto entero en un repositorio en línea y actualizarlo las veces que quieras y regresar a versiones anteriores por posibles fallos.
Herramientas de Diseño
Diseño gráfico Canva Lo utilizamos para la creación de diagramas de Gantt, diseños vagos de la aplicación y para la creación del cartel para prototipo.
Herramienta de colores HTML Colors Lo usamos para crear la paleta de colores que utilizamos en toda la aplicación.
