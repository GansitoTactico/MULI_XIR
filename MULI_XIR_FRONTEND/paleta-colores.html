Uso de la Paleta

Para usar estos colores en tu CSS, simplemente referencia las variables CSS definidas en :root:

color: var(--text-primary);

Para los gradientes:

background: var(--background-gradient);

Puedes usar los colores de acento para botones, enlaces y elementos destacados:

background-color: var(--accent-color-2);
